SHOP — СНИМОК ПРОЕКТА ДЛЯ ПРАКТИЧЕСКОЙ РАБОТЫ 4

Содержимое:
- HTML-страницы проекта;
- style.css — оформление и адаптивные стили;
- index.html подключает Bootstrap 5.3.3 через CDN.

Это версия на основе файлов, предоставленных после практической работы 5, подготовленная для показа HTML/CSS и Bootstrap (практические работы 2–4):
- убраны подключения script.js, чтобы не включать функциональность JavaScript из практической работы 5;
- страница товара сделана статической, чтобы не зависеть от JavaScript.

Важно:
1. Папка images в загруженных файлах отсутствовала. Скопируйте в эту папку изображений из своего исходного проекта, например images/serum.jpg, images/body.jpg и images/hair.jpg.
2. Bootstrap подключается через интернет (CDN).
3. Перед публикацией проверьте страницы в браузере.
